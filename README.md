# AI All-in-One

A starter full-stack AI assistant with:
- Chat
- Web search
- Image generation
- Website/code generation
- Simple live HTML preview

## Setup

### Backend
1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env`
4. Add your OpenAI API key to `.env`
5. `npm start`

### Frontend
1. Open a second terminal
2. `cd frontend`
3. `npm install`
4. `npm run dev`

Open the frontend URL shown by Vite.

Never put your OpenAI API key in the frontend.
